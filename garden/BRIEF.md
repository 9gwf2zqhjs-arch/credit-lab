# 말 걸면 자라는 정원 — 기획

2026-10-14 시작. 사용자가 고른 첫 작품.

## 한 줄
문장을 건네면 Claude 가 그 말로 식물 하나의 "유전자"를 정하고, 정원에 심어 천천히 자라게 한다.

## 경험
1. 화면 아래 입력창에 아무 말이나 친다 ("오늘 좀 지쳤어", "첫눈이 왔으면").
2. 씨앗이 떨어지고, 그 말로 정해진 모양대로 몇십 초에 걸쳐 자란다 (가지 뻗음·잎·꽃).
3. 정원에 식물이 쌓인다. 식물에 마우스를 올리면 심은 문장과 Claude 가 붙인 이름이 보인다.
4. 다시 열어도 정원이 남아 있다. 식물은 실제 시간에 따라 조금씩 더 자라고, 오래되면 시든다.

## 구조
- `garden/web/` — 정적 프론트엔드. Canvas 2D(또는 고정 버전 라이브러리)로 절차적 식물 생성
  (L-system 이나 재귀 가지). 같은 유전자 → 항상 같은 모양 (시드 고정).
- `garden/server/` — 작은 서버 (Python 표준 라이브러리 또는 Node, 의존성 최소).
  - `POST /api/plant {text}` → 식물 유전자 JSON 반환. 정원 상태는 `garden/data/garden.json` 에 저장 (gitignore).
  - `ANTHROPIC_API_KEY` 를 `garden/.env` 또는 환경변수에서 읽는다. **키가 없으면 mock 모드**:
    문장 해시로 유전자를 결정적으로 만든다. 클라우드 개발·테스트는 전부 mock 으로 한다.
- 유전자 JSON (예시, 바꿔도 됨): `name`(짧은 한국어 이름), `form`(나무/덩굴/풀/꽃/선인장 등),
  `branching`, `angle`, `growth_speed`, `leaf_shape`, `palette`(색 3–4개), `flower`(여부·모양),
  `lifespan_days`, `mood`(한 단어). 범위를 서버에서 검증·잘라낸다.

## API 사용 (매달 들어오는 API 크레딧 $100 으로 운영)
- 모델: `claude-haiku-5-5` (설정 하나로 바꿀 수 있게). 구조화 출력(JSON)으로 유전자만 받는다.
- 문장 하나당 호출 한 번. 같은 문장은 캐시.
- 비용 상한: 하루 호출 수 상한(기본 200)과 입력 길이 상한(200자)을 서버에 둔다.

## 범위 밖 (지금은)
- 배포·공개 URL, 로그인, 여러 사람 공유 정원. 로컬에서 `python3 -m ...` 하나로 뜨면 된다.

## 완료 기준 (1차)
- mock 모드로 문장 10개를 넣으면 서로 눈에 띄게 다른 식물 10개가 자란다.
- 새로고침해도 정원이 남는다.
- 서버 단위 테스트(유전자 검증·mock 결정성·상한) 통과.
- 실제 키 연결과 화면 확인은 로컬 맥에서 사용자와 한다.
